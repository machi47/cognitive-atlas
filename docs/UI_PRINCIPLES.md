# UI Principles

- The main conversation stays clean.
- The atlas is tree-first, not graph-first.
- Inspector panels expose map impact, sources, questions, and traces only when requested.
- Mobile uses `100dvh`, safe-area padding, 16px inputs, and a bottom nav.
- Quick capture is the first-use flow.
- Sessions remain easy to create, resume, fork, and archive.

The UI should feel like a fast thinking surface, not homework.
